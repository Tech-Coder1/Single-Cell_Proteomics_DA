# Synthetic Single-Cell Proteomics Analysis of Human Cerebellum

An end-to-end, reproducible computational portfolio project on a **simulated** single-cell proteomics experiment, inspired by published human postmortem brain proteomics workflows.

> **Important:** every observation is simulated. The data do not come from human donors, postmortem tissue or patients with frontotemporal dementia (FTD). Planted disease effects only test whether the workflow recovers known signals. This is a methods demonstration, not biological evidence.

## Study design

- 8,124 simulated cells x 3,217 protein features
- 8 donors: 4 Control, 4 FTD
- Five cell classes: Purkinje neurons, granule neurons, astrocytes, oligodendrocytes, microglia
- Donor-level replication: differential testing uses donor pseudobulk, not individual cells

## Workflow

1. Generate and save synthetic data
2. Quality control and filtering
3. Per-cell median normalisation
4. PCA, UMAP and Leiden clustering
5. Marker-based cluster annotation
6. Donor-level pseudobulk differential abundance within cell types (Welch t-test, BH FDR)
7. Benchmark recovery of planted effects; export tables, figures and a summary

## Getting started

**Google Colab:** open the notebook and run it top to bottom (the first cell installs packages).

**Locally:**

```bash
git clone <your-repo-url>
cd <your-repo-name>
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
jupyter lab
```

Open `notebooks/single_cell_proteomics_analysis.ipynb` and run all cells. Everything is regenerated from the random seed (`20261114`).

## Outputs

Written under `results/`: `figures/` (QC, PCA, UMAP, volcano plots), `tables/` (QC metrics, annotation confusion matrix, benchmark), `differential_analysis/` (per-cell-type results) and `analysis_summary.json`. Intermediate data go to `data/synthetic/` and `data/processed/`.

## Limitations

Simulated data, simplified measurement model, four donors per group, and a simple Welch test rather than a full covariate-aware model. See the final section of the notebook for details.

## Reference

Liu et al. (2022), *Single-cell proteomics reveals cell type-specific proteome landscapes in human postmortem brain*, Nature Communications. DOI: 10.1038/s41467-022-33338-0.
